## 1:20 — 2:00  영수증 OCR — 듀얼모드 (40초) ⭐

### 무엇
1. 사이드바 **지출입력** 클릭 → **+ 지출 등록**

### 말할 것
> *"한국 총무의 페인포인트 1순위가 영수증 입력입니다. 사진만 올리면 일자·공급가·부가세·가맹점이 자동으로 폼에 들어갑니다. 환경변수가 차단된 보안 환경에서도 동작하도록 Tesseract.js 한글 모델로 자동 fallback. 이게 진짜 production grade 의 차별점이라고 봅니다."*

## 3:00 — 3:30  전자결재 다단 + 이메일 (30초)

### 무엇
1. 사이드바 **전자결재** → **+ 새 결재 발의**
2. 유형 선택 → 제목 입력 → 결재선 2단계 (팀장 → 부장)

## 4:30 — 5:00  Q&A 대비 (30초 버퍼)

### 자주 받는 질문 + 답변

**Q. AI 키 비용은 얼마예요?**
> Gemini 2.5 Flash 무료 tier 가 일 100만 토큰이라 이 규모 회사는 평생 못 다 씁니다. 카드 등록도 필요 없습니다.

**Q. 더존이랑 뭐가 다릅니까?**
> 1) 자연어 질의 + 영수증 OCR (AI), 2) 한국 노무 리스크 자동 점검, 3) 모바일 PWA, 4) 데모 5초 진입. 더존이 더 풍부한 회계 기능은 가지지만 이 4개는 더존이 쉽게 못 따라옵니다.

**Q. 보안은요?**
> RLS 가 DB 레벨에서 역할별 격리, 미들웨어가 라우트 가드, audit log 가 모든 변경 추적. service_role 키는 `server-only` directive 로 클라이언트 노출 차단.

**Q. 1인 회사인데 어떻게 운영해요?**
> v1 은 1인 admin 가정. v2 멀티테넌시 (회사 단위 격리) 는 RLS 기반이 이미 잡혀있어 회사 ID 컬럼 추가 + 정책 확장만 하면 됩니다.

**Q. 모바일은요?**
> PWA 라 홈 화면 추가 가능. 반응형 + 44px 터치 타겟 + 하단 탭바. 네이티브는 Capacitor 로 v2.x 에서.
